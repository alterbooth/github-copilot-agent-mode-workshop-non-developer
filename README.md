# ABC-101 Anti-Inflammatory Research Project

## Overview

本プロジェクトでは、新規抗炎症候補化合物 ABC-101 の評価を実施しています。

研究対象は炎症性サイトカインの抑制効果であり、既存候補化合物 XYZ-201 および既知対照化合物 REF-001 と比較します。

## Objectives

評価対象

- IL-6抑制効果
- TNF-α抑制効果
- 細胞生存率
- 細胞毒性

## Current Status

実験1〜3を実施済み。

測定結果は results/assay-results.csv を参照してください。

## Known Limitations

- 長期毒性試験未実施
- 動物試験未実施
- 他研究との比較未実施
- 作用機序未確認
